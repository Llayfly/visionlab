# VISIONLAB · 智能视觉工作站

一个可本地运行的前后端项目，专注工地安全帽/头盔与反光衣检测：图像上传、YOLOv8 目标检测、视频流实时检测、数据统计与历史任务页面。

## 项目结构

```text
VISIONLAB_完整项目/
├─ frontend/
│  └─ index.html             # 网站界面
├─ backend/
│  ├─ __init__.py
│  ├─ main.py                # FastAPI 后端与检测接口
│  └─ models/
│     └─ README.txt          # 模型权重放置说明
├─ scripts/
│  ├─ 启动网站.bat           # Windows 一键启动
│  └─ 检查环境.bat
├─ requirements.txt
└─ README.md
```

## Windows 启动步骤

1. 安装 Python 3.10 或 3.11（安装时勾选 **Add Python to PATH**）。
2. 解压整个项目文件夹，不要只单独运行 `index.html`。
3. 双击 `scripts/启动网站.bat`。首次启动会创建 `.venv` 并安装依赖，可能需要几分钟。
4. 浏览器打开 `http://127.0.0.1:8000`。
5. 可访问 `http://127.0.0.1:8000/api/health` 检查后端状态。

## 模型配置

项目代码已提供真实检测接口，但**权重文件没有打包**：

- YOLOv8：将 `best.pt`（工地安全帽/头盔与反光衣检测，4 类）放入 `backend/models/`。

接口：
- `GET /api/health`：返回服务状态与检测权重是否就绪。
- `POST /api/detect`：表单字段 `file`（图像）与 `confidence`（0.01–0.99），返回目标数量、平均置信度、耗时与检测框。

若缺少权重，接口会返回清晰错误，不会伪造成功结果。

## 视频流说明

视频流检测支持两种模式：导入本地视频文件，或调用浏览器摄像头。前端每 3 帧抽取 1 帧、压缩至 640px 宽后调用 `POST /api/detect`，检测框按显示尺寸换算并用中文标签绘制，检测结果在帧间做平滑与短暂保持，避免标注框闪烁。

## 安全与使用

- 默认只监听 `127.0.0.1`，仅本机访问。
- 上传文件大小限制为 25 MB；图像限制为 4000 万像素。
- 当前为开发/本地演示配置，不建议直接暴露到公网。
